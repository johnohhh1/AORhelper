# AOR Helper - Area of Ownership Management App

**Restaurant Operations Management System for Chili's #605**

## Overview

AOR Helper is a comprehensive web application designed to help Culinary Leaders, Hospitality Leaders, and To-Go/Bar Leaders manage their Areas of Ownership efficiently. The app replaces manual tracking methods with a centralized, mobile-friendly platform.

## Features (Planned)

- **Role-Based Dashboards** - Customized views for Culinary, Hospitality, and To-Go/Bar leaders
- **Metric Tracking** - Track daily/weekly performance metrics with trend analysis
- **Task Management** - Automated recurring tasks with smart reminders
- **Team Management** - Track team member performance and coaching
- **Schedule Tracker** - Never miss the Monday 5pm schedule deadline
- **Big Swings Tracker** - Monitor quarterly initiative progress
- **Mobile-First Design** - Access anywhere in the restaurant

## Tech Stack

- **Frontend:** Next.js 14, TypeScript, Tailwind CSS, shadcn/ui
- **Backend:** Next.js API Routes
- **Database:** PostgreSQL (Supabase)
- **ORM:** Prisma
- **Hosting:** Vercel
